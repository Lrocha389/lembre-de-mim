# Lembre de Mim 💗



**Acesse:** https://lrocha389.github.io/lembre-de-mim/

## O que tem

- **Hoje** — a rotina do dia com checklist; um coração vai enchendo conforme ela marca as tarefas
- **Semana** — o que tem em cada dia
- **Cuidados** — lembretes de se cuidar
- **Abra quando...** — envelopes com cartinhas pra cada momento (saudade, dia difícil, insônia...)
- Bilhetinho diferente a cada dia e contador de dias juntos

## Como é feito

- HTML, CSS e JavaScript puros, sem framework e sem build
- PWA: instala na tela inicial do celular e funciona offline (manifest + service worker)
- O progresso das tarefas fica salvo no próprio celular (`localStorage`)
- Todo o conteúdo fica no objeto `CONFIG` e nas listas no começo do `<script>` do `index.html`, fácil de editar

## Instalar no celular

- **Android (Chrome):** abrir o link → menu ⋮ → *Instalar app* ou *Adicionar à tela inicial*
- **iPhone (Safari):** abrir o link → botão de compartilhar → *Adicionar à Tela de Início*
